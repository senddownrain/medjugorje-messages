Не запускайте их одновременно. Каждый следующий этап начинается только после проверок предыдущего. В каждой задаче прочитать `AGENTS.md`, `docs/AUDIT_VISIONARIES_2026-10-23.md`, `docs/SEARCH_V2_PLAN.md`.

## A. Высокоточный аудит — СНАЧАЛА

Изучи все семь JSON-архивов (899 ID) и скачанные пользователем MHTML. Не редактируй тексты. Проверь соответствие заголовков, дат, source ID, типов, визионеров и ссылок. Сверь с исходными тематическими страницами `/en/messages/annual/`, `/en/messages/special/`, `/hr/messages/annual/`, `/hr/messages/special/`, используя предоставленные сохранённые копии или разрешённые ответы сайта, не обходи HTTP 403. Не заявляй полноту архива без сравнения всех URL/ID по категориям.

Проверь конкретно: Иван 2006-09-08 (`060908s`), Иван 2014-08-12 (`140812s`, исходный URL ошибочно оканчивается на `140802s`), Мирьяна 2005-04-02 (`050402s`). Выдели ранние 159 записей еженедельных посланий приходу с неизвестным адресатом; не приписывай их автоматически Марии. Раздели `visionary` (получатель), `type` и `series`, включая ежегодные даты и особые исключения 1985-05-07 / 1998-09-12.

Подготовь проверяемую таблицу diff и аудиторский отчёт с ссылками на оригинал, уровнем уверенности, логом аномалий, точными количествами, отдельно `source-missing` и `translation-not-present`. Содержимое `text`, `segments`, `text_sha256`, старые URL и канонические ID не менять. Все изменения в Draft PR, без merge/deploy. Команды `python3 -m unittest discover -s tests -v`, `npm run check:data`, `npm run build`; результаты PASS/FAIL/NOT TESTED.

## B. Семантическая модель и поиск

После одобрения PR-A введи `series` и проверенные значения `visionary` в отдельной производной метадате (не редактируя оригинальные языковые JSON). Предусмотри `unattributed`, частичную уверенность и источник классификации. Добавь по всему локальному содержимому выбранного языка клиентский поисковый индекс с Unicode-нормализацией для RU/BE/UK/HR/EN/SK/LV и корректной подсветкой совпадений без XSS. Разреши поиск без слова — только фильтрами; серии, визионер, тип, год, диапазон дат, совпадение слов/фразы. По умолчанию сортировка по дате. Напиши unit/e2e проверки реальных случаев; не теряй ID после смены языка. В PR нужны замеры задержки поиска на Android-подобной низкой производительности.

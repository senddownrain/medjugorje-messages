# Codex Cloud: работа с Medjugorje Messages с телефона

Это инструкции именно для **Codex Cloud (OpenAI)**, не для Claude и не для GitHub Codespaces.

## Что уже готово в приватном GitHub

- `main` содержит исходники PWA (Vue 3, Vuetify 3), семь JSON-архивов и общий индекс.
- `AGENTS.md` объясняет Codex логику проекта и запреты на изменение текстов посланий.
- `scripts/setup-cloud.sh` устанавливает зависимости, проверяет JSON, Python-тесты и производственную сборку.
- GitHub Actions создает **приватный архив `dist`**, запускает тесты при PR и изменениях `main`.
- Мониторинг официальных новых дат и пяти общественных RSS идет отдельно; он не публикует тексты.

## Один раз: создать облачную среду

1. На телефоне откройте Chrome, перейдите на https://chatgpt.com/codex под своим аккаунтом ChatGPT. **Создавать и публиковать новую среду можно через веб-версию**; если интерфейс неудобен на мобильной ширине, включите в Chrome «Версия для ПК». После создания задачами можно управлять из мобильного приложения.
2. В новой задаче выберите **Work in → Cloud → Select environment → Create environment**. Другой путь — **Settings → Codex Cloud → Environments → Create environment** (если этот пункт доступен).
3. Подключите GitHub, если требуется; выберите только приватный репозиторий `senddownrain/medjugorje-messages`, исходная ветка `main`. Имя среды: **Medjugorje Messages**.
4. Нажмите **Get started**. Пусть Codex сам исследует репозиторий. В диалоге попросите прочитать `AGENTS.md` и подготовить Node.js 22+, Python 3.12, зависимости `npm` и `pip`. В качестве тестируемого **Install script** используйте `bash scripts/setup-cloud.sh`.
5. Интернет только для реестров пакетов npm/PyPI (профиль **Package managers**, если требуется). **Не добавляйте Firebase credentials, приватные токены и production-секреты**.
6. Просмотрите отчёт тестирования. При ошибке поручите Codex исправить setup; когда готово — **Save → Publish**. Приватность **Only me**.
7. После `Environment published` выбирайте **Start a new task**, опубликованную среду и описывайте работу. В мобильном приложении Codex эта среда появится как доступная.

Состояние среды сохраняется для новых задач, но каждый запуск имеет **изолированные рабочие файлы**. GitHub PR/коммит фиксирует сделанное. Это не постоянно работающий веб-сервер.

## Первый запрос в созданную среду

> Используй приватный репозиторий senddownrain/medjugorje-messages, ветку main. Прочитай AGENTS.md и docs/CODEX_CLOUD.md. Проверь среду, все 7 архивов и их SHA256, прогони Python-тесты, npm run check:data и npm run build. Исправляй обнаруженные ошибки в отдельной ветке и создавай PR, не изменяя тексты посланий. Не публикуй приложение. Разберись с проверкой PWA на телефоне: предложи конкретный способ **приватного HTTPS-превью**, но не включай публичную публикацию без согласия. В отчёте укажи, какие проверки прошли, а какие (Android / визуальные / офлайн) не удалось выполнить.

## Как будем работать

- В обычном чате ChatGPT: обсуждать структуру посланий, католическую терминологию, макеты и решения.
- В Codex Cloud: выполнять изменения исходников, импорт, тесты, анализ, PR и сборки без Codespaces.
- В GitHub Actions: непрерывно валидировать базу и сборку на каждый PR.
- На телефоне: открывать готовое [приватное HTTPS-превью](TESTING_PREVIEW.md) через вход в ChatGPT. Обновление Sites пока выполняется по поручению Codex. Codex Cloud **не предоставляет постоянно работающий публичный адрес приложения автоматически**.

### Что пока не проверено

Реальные Android-скриншоты на 320/390px, установка PWA, SafeArea, service worker offline, доступность интерфейса — это отдельные тесты, не следствие успешной команды `npm run build`. Не отмечать их успешными без фактического прогона.

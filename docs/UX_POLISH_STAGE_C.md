## Что изменилось

**A — фильтры.** Поиск работает сразу. Панель закрыта по умолчанию, при открытии
содержит четыре параметра: визионер, тип послания, год, месяц. Для имён и типов
выделена полная ширина, год/месяц стоят рядом. По умолчанию «Все / Все типы /
Все годы / Все месяцы». Сохранена категория «Не указан» для неизвестного получателя:
это не седьмой визионер и не новая атрибуция.

Месяц фильтруется по месяцу исходной даты независимо от года. Сентябрь при
«Все годы» возвращает сентябрьские записи разных лет; 2020 + сентябрь — их
пересечение. Результаты обновляются автоматически. «Сбросить» виден только при
активных фильтрах, снимает ограничения и **сохраняет текст запроса**.

В UI больше нет серии, точной даты/периода, режима поиска, диакритики и переключателя
пропусков перевода. Поле поиска одно. Фразы по-прежнему вводятся в кавычках.
Внутренний API B сохраняет серии, даты/периоды, режимы, политику атрибуции и
availability; добавлен независимый месяц. Старые записи истории очищаются от
удалённых UI-параметров, чтобы невидимые фильтры не ограничивали результат.

**B — языки и темы.** Нижний лист содержит только язык интерфейса и язык посланий.
Оба сохраняются независимо. Солнце/луна переключает тему одним нажатием без
открытия листа; выбор сохраняется. Третьей кнопки нет. При первом посещении без
явного выбора учитывается системная тема, после нажатия сохраняется светлая/тёмная.

**C — чтение.** Заголовок: «Последнее послание» только для действительно последнего
доступного текста языка → дата → полное имя → человеческое название подтверждённого
типа → небольшой золотистый разделитель → исходный текст. Неизвестный тип не
получает заглушку. Технических статусов серий нет ни в чтении, ни в карточках.
Восьмилучевой знак удалён из шапки, подписи и подвала. Название бренда сохранено,
новый логотип и иллюстрация не создавались.

Полные имена — только подписи UI, не изменение данных. RU использует формы из
задания владельца; BE/UK — кириллические формы, LV — латышские, HR/EN/SK —
исходное хорватское написание с диакритикой (без автоматического добавления
словацких фамильных окончаний). Все формы собраны в `visionaryLabels` для проверки.
Имена в исходных заголовках/текстах не переписывались. У неизвестного получателя
остаётся «Не указан», у восьми кандидатов — видимая пометка ожидания утверждения.

**D в этом задании — только регрессия.** Этап D проекта с lazy loading/PWA не
начинался. Сохранены реальные module Worker, очередь и защита от устаревших
ответов/ошибок, безопасная подсветка, `#message/id`, совместимый `#archive`,
Back/Forward с запросом, четырьмя фильтрами, языком, пагинацией, фокусом и scroll.
Недоступный перевод открывается по прямой ссылке с ручным выбором доступных языков,
без подстановки чужого текста. Поисковые результаты всегда относятся к выбранному языку.

## Сохранность и оставшиеся вопросы

Все восемь JSON, модель B, аудиты A/B, машинные протоколы и PNG первоначального C
не изменены. В старые документы C добавлены только ссылки на актуальный polish.
Проверка побайтная и по SHA-256: 899 ID, 8 pending, 154 неизвестных сохранены.
Пять снимков «до» скопированы побайтно из первоначального C, без редактирования
изображений; 29 снимков «после» сделаны браузером на финальной сборке.

PR #15 не менялся. `vite.config.js`, `src/main.js`, staging, workflow приватной
сборки и политика загрузки index + семи JSON сохранены. Проверка совместимости
веток не означает проверку HTTPS-публикации. Старый QA-скрипт #15 с селекторами
старого экрана потребуется согласовать с новым UI перед отдельным превью.

Остаётся: визуальная оценка владельцем, физический Android/клавиатура/PWA,
отдельное редакционное решение по восьми атрибуциям. Сохраняется предупреждение
Vite о большом основном JS (~1,26 MB до gzip): стартовая загрузка и кеши относятся
к отдельному этапу D, который здесь не запускался. Известных незакрытых
функциональных ошибок после локальных проверок нет.

## Четыре действия для визуальной приёмки с телефона

1. Открыть [галерею](UX_POLISH_SCREENSHOTS.md) в GitHub, сравнить чтение «до/после»
   на 390 и 320 px: имя, тип, интервалы, отсутствие звёздочки и технических серий.
2. Открыть снимки фильтров 320/390: оценить читаемость четырёх полей и «Сбросить».
3. Сравнить языковой лист и светлую/тёмную темы: только два языка, спокойные цвета.
4. Посмотреть Вицку и запись без перевода: длинное имя помещается, pending виден,
   чужой текст не подставлен. Замечания оставить в ревью этого PR.

Это статическая визуальная оценка. Интерактивная приёмка на телефоне потребует
отдельно разрешённого приватного превью; действующий сайт этим PR не обновлялся.

# Рабочее пространство Claude Code (из телефона)

Это **облачная разработка кода**, а не GitHub Codespaces. Периодическое управление редактором на телефоне не требуется.

## Однократное подключение (действия владельца)

1. Откройте **https://claude.ai/code** или вкладку **Code** в мобильном Claude.
2. Авторизуйтесь в Claude и подключите GitHub, если сервис предложит. Предоставьте доступ **только** к приватному репозиторию `senddownrain/medjugorje-messages`, если доступен выбор конкретных репозиториев.
3. Выберите репозиторий `senddownrain/medjugorje-messages` и ветку **main**.
4. Используйте облачную среду Default или создайте именованную среду **Medjugorje Messages** (если этот выбор отображается). Для setup-команд используйте `bash scripts/setup-cloud.sh`. Понадобится доступ к обычным npm/PyPI пакетным реестрам, **без секретов Firebase**.
5. В первой задаче попросите Claude прочитать `CLAUDE.md`, проверить установку и запустить команды `npm run check:data`, `python3 -m unittest discover -s tests -v`, `npm run build`. Попросите отчёт; если установка не проходит, исправить окружение, не меняя базу посланий.

Примечание: в Claude Code каждый запуск создаёт **изолированную облачную сессию**; повторно используется конфигурация окружения, но это не постоянно включённый сервер. Часть настройки Claude требует авторизации в аккаунте владельца, которую нельзя выполнить из ChatGPT через GitHub.

## Постоянный режим

- Задачи начинаются в Claude Code на телефоне: репозиторий → задача → Claude создаёт ветку/PR.
- GitHub Actions автоматически проверяют сборку, все JSON и Python-тесты; приватный `dist/` становится доступен как artifact.
- Сначала тесты, потом исправления, отчёт о проверках и PR. Не сливать PR без проверки.
- Визуальное тестирование браузера и установка PWA **не подтверждаются** только CI; для просмотра нужен приватный HTTPS-превью или forwarded port.
- Готовые импортированные тексты остаются приватными. Не публиковать PWA в GitHub Pages без согласования.

## Первый промпт в Claude Code

> Работаем с приватным репозиторием senddownrain/medjugorje-messages из ветки main. Прочитай CLAUDE.md и docs/CLAUDE_CLOUD.md. Проверь версии Node/Python и выполни bash scripts/setup-cloud.sh. Подтверди контрольные суммы семиязычной базы, прогони Python-тесты и npm build. Проверь, готов ли проект к просмотру на Android через приватный HTTPS-превью, и предложи безопасный способ без публичного размещения архивов. Самостоятельно исправляй ошибки сборки и тестов в отдельной ветке, создавай PR. Не изменяй тексты посланий, не публикуй сайт и не подключай production-секреты. В конце пришли точные результаты тестов и шаги проверки с телефона.

случаев **не установлено**, а не «ноль». Статус источников — `NOT_PROVIDED` в
[sources.json](../reports/stage-a/sources.json).

## Воспроизведение и оставшаяся сверка

Команда без исходников создаёт детерминированные отчёты:

```bash
python3 -m scripts.audit_stage_a --out reports/stage-a
```

Код завершения **2** означает незавершённую проверку оригиналов. Код **1** —
структурные нарушения JSON. Программа намеренно не выдаёт код 0 и не объявляет
полноту без ручной проверки разделов и пагинации. Запуск не делает сетевых запросов.

Для источников нужен локальный манифест такого вида (пути относительно манифеста):

```json
{
  "sources": [
    {"language":"en", "category":"all", "path":"en-all.mhtml", "url":"https://www.medjugorje.ws/en/messages/all/"},
    {"language":"en", "category":"annual", "path":"en-annual.mhtml", "url":"https://www.medjugorje.ws/en/messages/annual/"}
  ]
}
```

Это пример, а не список реально полученных файлов. Команда после их получения:

```bash
python3 -m scripts.audit_stage_a --sources saved/sources.json --out research-output/stage-a-with-sources
```

Нужны семь исходных полных архивов и четыре тематических снимка:
EN/HR `/messages/annual/`, `/messages/special/`. Если это страницы-указатели,
нужны также сохранённые страницы всех перечисленных подразделов и пагинации.
Тематические RU и индивидуальные страницы помогут разобрать обнаруженные
расхождения. Файл ZIP в `data/` содержит предыдущие JSON/отчёты трёх языков,
а не исходные MHTML, поэтому не заменяет их.

Сверщик фиксирует хеш MHTML, `Content-Location`, исходные заголовки и ближайшие
названия разделов, все ID и аномалии парсера; сравнивает дату, тип, slug, URL,
заголовок, текст, сегменты и хеш. Ссылки навигации не считаются сообщениями.
Несовпадение адреса или страница без датированных заголовков даёт непроверенный
статус, а не пустой архив. Обратная разность множеств строится только для `all`;
для тематических страниц нужна ручная оценка охвата. Данные не переписываются.
Заголовки в JSON доступны полностью в
[inventory.json](../reports/stage-a/inventory.json), по всем ID и имеющимся языкам.

# Публичный релиз GitHub Pages

Адрес: https://senddownrain.github.io/medjugorje-messages/

Владелец явно разрешил интеграцию, merge и публичную публикацию 24 октября 2026. Видимость репозитория и Pages владелец настроил самостоятельно.

## Состав

Интеграционная ветка основана на #22 (D), который уже включает зависимости #16 → #17 → #18 → #19 (A/B/C). Семь языков выбираются независимо от языка интерфейса. Последнее послание загружается первым; архив, поисковая модель и Worker — по запросу. Восемь исходных JSON и производная модель B сохранены побайтно. Pending-атрибуции не утверждаются.

Поисковый UX из #23 заменён: лупа справа открывает отдельный экран, результаты прокручиваются на странице, строка поиска закреплена снизу. Sliders внутри строки открывает только четыре фильтра в нижнем листе. Системный Back и Escape закрывают фильтры; Back/Forward из послания возвращают запрос, фильтры, количество карточек, прокрутку и фокус. Используются visualViewport, SafeArea и `interactive-widget=resizes-content`.

#15 и #20 относятся к отдельному приватному Sites-превью; его deployment и настройки доступа не изменяются. #21 не входит в релиз. Нового автоматического импорта, автоматического утверждения текстов или включения автослияния нет. Существующие watchers обнаруживают кандидатов для ручной проверки.

## Сборка и доказательства

`.github/workflows/pages.yml`: pull request запускает проверки, push в main запускает те же проверки, затем публикацию проверенного `dist` через официальные configure/upload/deploy Pages actions. Permissions: только contents:read для проверок; pages:write/id-token:write только для deployment. Ни один production-секрет не попадает в клиент.

`npm ci`, `check:data`, `check:search-metadata`, поисковые Node-тесты, Python-тесты, настоящий Worker, production build, проверка артефакта, мобильная матрица 320/390 × семь языков × две темы, production PWA offline и синтетические обновления кеша являются обязательными до deployment.

После deployment отдельный job `verify-public` обращается к публичному HTTPS без авторизации, ждёт SHA из `release.json`, сверяет хеши семи опубликованных архивов с репозиторием и выполняет мобильные/PWA-проверки. Реальные PNG и JSON доступны в Actions → артефакт `public-release-proof`. `release-tests` содержит локальные проверки, в том числе неудачную и успешную установку новой оболочки, data-only update и сохранение ранее загруженного LV офлайн.

`release.json` содержит SHA сборки и SHA-256 восьми исходных JSON. Manifest и SW имеют scope `/medjugorje-messages/`; PNG-иконки включают maskable. `scripts/check-dist.py` проверяет отсутствие noindex, исходных MHTML/ZIP, отчётов и признаков ключей в dist.

## Проверка с Android

1. Открыть адрес в обычной вкладке Chrome. Через кнопку RU сменить отдельно язык интерфейса и послания; проверить семь языков и тему.
2. Нажать лупу и ввести слово. Результаты должны быть над нижней строкой. Открыть sliders, выбрать год и визионера, закрыть лист. Результаты и индикатор фильтров остаются.
3. Сбросить фильтры, прокрутить результаты, открыть послание и нажать системный Back: запрос и позиция возвращаются. Проверить Forward и перезагрузку прямой ссылки.
4. В меню Chrome выбрать «Добавить на главный экран» → «Установить». Сначала открыть нужные языки и их поиск онлайн, затем включить авиарежим и повторно открыть приложение. Незагруженный язык должен показать явную ошибку; чужой текст не подставляется.
5. Когда появится предложение обновления, нажать «Обновить» и проверить сохранённый язык и офлайн. Первая установка и смена ещё не загруженного языка требуют интернета.

Физический Android, системная клавиатура и установка через меню ОС не подменяются эмуляцией Chromium: до проверки на устройстве их статус NOT TESTED. DevTools installability проверяет техническую устанавливаемость, а не действие пользователя в Android.

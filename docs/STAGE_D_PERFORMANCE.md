Реализовано в отдельном Draft [#22](https://github.com/senddownrain/medjugorje-messages/pull/22) поверх актуального #19 (`5356e4b`). Базовая сборка C сделана до коммита документации, из побайтно тех же исходников UI `3653ce8`. Финальная измеренная реализация: `cf264a6`. Merge и публикаций нет.

Первый экран получает shell + compact manifest + один latest выбранного языка. Архив, metadata, catalog/controller и Worker отложены до поиска/deep-link, остальные языки — до выбора. Четыре recent-карточки заменены кнопкой архива. Политика кеша/обновления и команды: [PWA.md](PWA.md).

## Методика

Chromium 154.0.8037.57, production dist, localhost HTTP gzip level 9. Для каждого профиля три независимых browser contexts; внутри cold → repeat → offline. Repeat использует уже установленный SW и сохранённые RU/EN/search assets; каждый запуск начинается в RU. Это эмуляция, **не физический Android**.

Нормальный профиль: 80 мс задержки ответа, общая полоса 1 250 000 bytes/s (~10 Mbit/s), CPU страницы ×4. Медленный: 150 мс, 200 000 bytes/s (~1,6 Mbit/s), CPU ×6. Общий серверный shaper ограничивает **все** ответы, включая запросы Worker и SW; отдельный CDP network throttle страницы этого не гарантирует и в финальном сравнении не используется. CPU Worker/SW не замедлен.

Время текста — первое наблюдение видимого `.message-text` от navigation start. Взаимодействие — успешное переключение темы после текста: это проверенная верхняя оценка готовности, **не стандартная метрика TTI**. Поиск — первое открытие плюс реальная RU-фраза, построение индекса и готовый результат; включает автоматизированный ввод и наблюдение. RU→EN измеряется при открытом поиске с сохранённой RU-фразой (честный пустой EN-результат).

Объём — реально отправленные сервером сжатые тела до наблюдения первого текста, включая фоновые загрузки установки SW. HTTP-заголовки, TLS/DNS/внешний хостинг не моделируются. Дополнительные CDP/ResourceTiming значения оставлены в JSON как диагностика: они могут не учитывать запросы SW и не используются как полный трафик.

Первое открытие поиска и первый другой язык оплачивают отложенную загрузку; некоторые repeat/search/lang сценарии медленнее C. Снижение трафика не выдано за ускорение каждого действия.

Worker heap измерен настоящим `Runtime.getHeapUsage` через CDP target Worker после активного EN-индекса. Это моментальный V8 usedSize, включая ещё не собранный мусор; не Android RSS, не total process memory и не retained heap после forced GC. На главном экране D этого Worker нет. Все min/max и остальные поля доступны в [summary.json](../reports/stage-d/summary.json), сырые [before.json](../reports/stage-d/before.json) / [after.json](../reports/stage-d/after.json).
